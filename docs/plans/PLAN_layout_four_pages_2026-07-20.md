# 面向用户布局重构计划 · 四页面导航

> 生成日期：2026-07-20 ｜ 状态：**待用户确认**（确认后再做预览细化与上线）
> 目标：把「一个超长首页 + 若干独立路由」的现状，重组为四个**可选择、地址可分享**的顶层页面，采用一流工具站的常驻导航范式，视觉沿用品牌红但更简约现代。

---

## 0. 已与用户确认的三项决定

1. **首页方案 = 检索页即首页**：顶部四标签常驻导航，访问 `/` 直接落在「检索」页，不再单设油画大 hero 落地页。公告 / 注册用户分布 / 社区 / 用户反馈**精简后并入检索页**（右辅栏 + 折叠 / 右下角入口）。
2. **联想检索去向 = 两者都保留**：检索页保留完整「引文检索」面板，内含 `标准检索`（精确/模糊）+ `联想检索`（AI 找相关论述）两个子标签。
3. **视觉风格 = 同色系更简约现代**：保留品牌暗红 `#8f1d1d` 与宣纸暖色气质，但走更简约现代——更轻的卡片、更清晰的层级、更多留白，接近 Linear / Stripe 的清爽感。

**默认归位（未点名项，可推翻）**：外文文库已并入**阅读文库**（著作目录），在「阅读」页书目网格中作为外文原著卡出现、点入网页版 `wenku_reader`，**不单列于「进阶功能」**；会员套餐 / 账户 / 登录注册 / 控制台后台 → 顶部导航右侧账户区，不占四个主标签；继续阅读历史 → 阅读页（检索页顶部可选出现）。

## 1. 研究：一流网站前端布局的通用法则

综合 Stripe / Linear / Vercel / Notion / Apple / GOV.UK / 维基 / 知乎 等站点，及 2025 导航设计共识，可落地的法则：

| # | 法则 | 对本站的含义 |
|---|------|-------------|
| 1 | **顶层导航 5–7 项以内，越少越清爽**（2025 趋势：极简、降低认知负荷） | 我们只有 **4 项**，正是理想区间，不需要下拉分组 |
| 2 | **主次分离**：主导航只放核心去处，账户 / 登录 / 会员等次要动作收到最右或头像菜单 | 四个主标签绝不与「会员套餐 / 登录 / 后台」混排 |
| 3 | **全站一致 + 常驻（sticky）+ 当前页高亮**：单一高亮态回答"我在哪" | 抽出统一外壳，四页 + `/ai` + 辞典 / 流式 / 期刊 / 文库全部共用同一条导航 |
| 4 | **层级靠排版而非线框**：留白、字号字重、分组来分层，减少"又描边又重阴影"的堆叠 | 卡片改为 1px 极淡描边 **或** 一层很轻的阴影（二选一），圆角统一 |
| 5 | **8pt 间距网格**：统一的间距 / 圆角节奏 | 区块间距 24–32、卡内 16–20、圆角 14–16 |
| 6 | **移动端**：≤5 区块用**底部固定标签栏**（拇指可达、功能发现率比汉堡高 30%+） | 4 页非常适合底部 Tab；次要项收进右上账户 |
| 7 | **阅读区限制最大宽度**（正文 ~70–75 字符宽），工具区可更宽 | 检索工作区 ~1040px；结果 / 长文正文收窄，避免超宽行 |
| 8 | **一个主色、克制使用**：强调色只用于当前态 / 主按钮 / 链接，大面积回归中性 | 暗红只做重点，大面积回暖白，让红更有力 |
| 9 | **按用户旅程排序**，不是按组织结构 | 标签顺序：检索（核心动作）→ 阅读 → AI 研究对话 → 更多功能 |

来源：[Mobbin — Top Navigation Bar](https://mobbin.com/glossary/top-navigation-bar) ｜ [O-WOW 2025 Top Bar Trends](https://o-wow.com/website-top-bar-navigation-design-in-2025/) ｜ [NN/g Mobile Navigation Patterns](https://www.nngroup.com/articles/mobile-navigation-patterns/) ｜ [Onething — Hamburger vs Tab Bar](https://www.onething.design/post/hamburger-menu-vs-tab-bar)

## 2. 总体架构：全站统一外壳（App Shell）

引入一个复用的**导航外壳**，四页与所有二级页共用，保证全站一致：

```
┌─────────────────────────────────────────────────────────────┐
│  [马恩经典·检索]   检索  阅读  AI研究对话  更多功能    会员套餐 · 账户▾ │  ← sticky 顶栏
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    当前页正文（四选一）                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
移动端：顶栏只留 [Logo] 与 账户；底部固定四标签栏（图标+文字）
┌───────┬───────┬───────────┬────────┐
│ 检索  │ 阅读  │ AI研究对话 │ 更多   │   ← 底部 Tab（当前态红）
└───────┴───────┴───────────┴────────┘
```

- **左**：站点标识（小红标 + 衬线字标）。点击回检索页。
- **主标签**：检索 / 阅读 / AI研究对话 / 更多功能，当前页红色高亮（下划线或红底 pill）。
- **右账户区**：未登录 = `会员套餐` + `登录` + `注册`；已登录 = `会员套餐` + 头像菜单（账户中心 / 本地控制台 / 管理后台按权限 / 退出）。
- **移动**：顶栏收成 Logo + 账户按钮；四个主标签下沉为**底部固定标签栏**。

**技术形态**：四个**真实路由**、服务端渲染、各自权限门控、URL 可分享、当前标签高亮。**不做**"一个页面 JS 切 4 段"的伪 SPA（会破坏可分享地址、后端权限门控与深链）。

## 4. 四页详细布局

### ① 检索页 `/`（默认首页 · 当前态：检索）
- **主工作区**（居中，最大宽 ~1040px）：
  - 页标题「引文检索」+ 一句副标题（把需要核查的原文粘贴进来，定位原著出处）。
  - 子标签：`标准检索` ｜ `联想检索`（沿用现有逻辑与文案键）。
  - 大输入框 → 同段共现开关 + 检索范围 chips（联想/研究用）→ 提交 + 历史检索记录。
  - 结果框（沿用 `resultsBox`：书库分栏 tabs、引用格式选择、可拉伸高度）。
- **右辅栏**（桌面 ≥960px，窄栏）：公告卡（收窄）· 注册用户分布地图（可折叠）· 社区跑马灯（弱化）。
- **用户反馈**：右下角小入口（沿用现 feedback 组件），不常驻占版面。
- **品牌条**：不再整屏油画 hero；顶栏即品牌。检索页给一条克制的品牌行（标题 + "收录 N 种文献" 折叠 chip），可选保留一小幅油画点缀。
- 移动端：辅助内容下沉到检索区下方、单栏。

### ② 阅读页 `/read`（当前态：阅读）
- **篇章直达大搜索框**：粘书名 / 篇名直达；含"切换书库（全部 / 指定库）"下拉（沿用现逻辑）。
- **继续阅读条**：有本设备记录才显示，一键回到上次阅读处。
- **书库网格**：各文献集卡片（马恩文集 / 全集 / 全集二版 / 选集 / 列宁 / 毛 / 邓江胡 / 习系列 / 党代会…，以及**外文原著**：俄文列宁全集 / MEGA² / MEW / 英文，点入网页版 `wenku_reader`），点开进阅读器；每卡标注"内置 AI 导读"。外文文库已并入此处，不再单列。
- **阅读器 `/viewer` 不变**：已内置 AI 导读、查找本书、引文报错等；仅顶部套统一外壳。

### ③ AI研究对话 `/ai`（当前态：AI研究对话）
- **原样保留**：快速问答 / 研究综述深度切换、模型选择（Flash/Pro/GLM）、检索引文库作答开关、检索范围 chips、额度徽章、连续上下文会话。
- 仅把它自带的 `.aip-topbar`（"← 返回首页"）**并入全站统一外壳**，当前态高亮到本标签。

### ④ 进阶功能 `/more`（当前态：进阶功能）
- **卡片网格**（权限感知）：大辞典 · 流式阅读 · 期刊订阅（+ 未来扩展位）。每卡：标题 + 一句用户收益说明 + 按钮（已开通=进入 / 未开通=查看会员套餐）。
- **外文文库不在此**：已并入「阅读」页书目网格（外文原著卡 → `wenku_reader`）。
- 可选把"关于 / 联系 / 数据版本 / 收录文献全清单"等信息区也放这里。
- 点入各自现有页：`/dictionary`、`/liushi`、`/journal-alerts/latest`。

## 5. 视觉系统（保留品牌红 · 更简约现代）

**色板（在现有基础上提亮、减装饰）**
| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#f7f4ef` | 页面暖白底（比现 `#f4efe8` 更净） |
| `--surface` | `#ffffff` | 卡片 |
| `--surface-2` | `#fbf8f3` | 次级块 / 输入底 |
| `--line` | `#eae2d6` | 1px 描边（比现 `#decfbd` 更淡） |
| `--text` / `--muted` | `#221c16` / `#756a5f` | 正文 / 次级 |
| `--accent` / `--accent-deep` | `#8f1d1d` / `#6f1717` | 品牌红：当前态、主按钮、链接 |
| `--accent-soft` | `#f6e9e6` | 红色柔底（当前 pill / 标签） |
| `--ai` | `#264653` | AI 页强调（克制） |

- **卡片**：1px `--line` 描边 + 极轻阴影（`0 1px 2px rgba(0,0,0,.04)`）二选一为主，圆角 14–16px；**去掉又描边又重阴影的叠加**。
- **间距**：8pt 网格；区块 24–32、卡内 16–20。
- **字体**：标题思源宋体（品牌感）；正文 / UI 用系统无衬线（雅黑 / Noto Sans）。层级靠字号字重，不靠色块。
- **导航**：暖白 + 1px 底描边 + 轻毛玻璃（sticky）；当前标签红下划线或红底 pill。
- **按钮**：主=红实心、次=描边、禁用=灰；统一高度圆角。
- **克制大色块**：现油画 hero 占屏过多 → 收敛为顶栏品牌 + 检索页一条品牌行。

- **JS/CSS 平移**：检索逻辑、`resultsBox`、篇章直达 JS、`reading-history` 模块、feature_tags 大多可原样搬迁。
- **后端上下文拆分**：`_index_feature_cards()` 等按页拆分注入；权限门控沿用；`site_text` 键复用 / 新增。
- **配置 / 部署清单**：站点文案自动注入、新静态加入 `cloud_patch_files.txt`、范围化 `update_cloud` 清单相应更新。

## 9. 风险与部署注意（呼应历史踩坑）

- **单一共享工作树 + 单生产机**：勿并发部署；范围化清单 **≥2 行**；diff 基准用 **scp 下来的服务器现行文件**，剥离外来 WIP hunk（模板叠了大量用户 WIP）。
- 新静态务必加入 `cloud_patch_files.txt`；`update_cloud` 不验 `/viewer`，须**服务器侧自查**（模板 NUL 哨兵 `grep -a`）。
- **本地全验**：Flask + 应用内浏览器端到端跑通四页 + 三种权限态（游客 / 会员 / 管理员）+ 移动端底部 Tab。
- **深链不破**：`/viewer?page=`、`/dictionary/entry/...`、`?from=journal` 等保留。
- **回滚预案**：字节级备份 + 一条 `cp` 还原；先灰度自查再对外。
