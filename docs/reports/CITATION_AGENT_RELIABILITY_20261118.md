## 调查与处理

- 生产只读排查时，两个 Agent 后台服务均已停止，两份任务停在提取阶段且无人领取。新版在发布事务内恢复后台服务，就绪前向会员提示稍后上传，已领取的任务使用心跳、执行时限和检查点恢复。
- 历史记录中有 24 次队列校验失败。新版队列以不透明编号绑定用户选择的公开来源，覆盖最多 500 项，模型只能对本轮候选给出判断。
- 历史上有 58 条近似候选已被接受却没有写入。新版统一审核与导出的证据判断。直接引文在所选书库中有唯一完整出处、印刷页码可靠、仅有一至两处轻微差异，且经模型同意后，可自动插注。审核界面与 Word 批注均保留逐字差异。疑似底本错误可由用户另行提交核查。
