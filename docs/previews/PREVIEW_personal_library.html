德意志意识形态

第一卷 · 费尔巴哈

迄今为止人们总是为自己造出关于自己本身、关于自己是何物或应当成为何物的种种虚假观念。他们按照自己关于神、关于模范人等等观念来建立自己的关系。

他们头脑的产物就统治他们。他们这些创造者就屈从于自己的创造物。我们要把他们从幻想、观念、教条和想象的存在物之下解放出来。

意识在任何时候都只能是被意识到了的存在，而人们的存在就是他们的现实生活过程。这种历史观和唯心主义历史观不同，它不是在每个时代中寻找某种范畴。

而是始终站在现实历史的基础上，不是从观念出发来解释实践，而是从物质实践出发来解释各种观念形态。
