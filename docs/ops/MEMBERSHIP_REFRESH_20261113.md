## 推送准备复核（2026-11-13）

远端 main 和 production 在核对时均为 ba1d884aeac0cd1bb2a505eaf2971920f350e29b。API 兼容夹具采用 Pro 资格，REST 断言覆盖新队列与独立控制通道。全量 CI 为 MCP 夹具单独配置 Python 3.11，主应用集成门禁仍使用 Python 3.10。13 项此前未在本次任务运行的 API 兼容检查首次通过。具体版本、场景和文件哈希见 release-fixtures.json，JUnit 见 release-fixtures.xml。

正式发布尚有一处数据切换风险。deploy/promote_release.sh 以与正式服务相同的 www-data 用户启动候选服务，会员库位于该用户的共享数据目录。候选虽然设置 MARX_SKIP_STARTUP_MAINTENANCE=1，app.py 导入时仍执行 init_membership_db()，该调用会种入新 Plus 并停售旧套餐。候选启动后，旧程序可能提前读到新的商品状态。拒绝候选或回滚应用也不会撤销已写入的会员库变更。

发布前须明确候选阶段的会员库隔离与正式生效点，并验证拒绝候选时线上商品状态保持原样。还须确认回退版本能够处理新 Plus 订单及钱包，且回退后保留上线期间的写入。样刊准备脚本须在与线上服务一致的运行用户和数据环境下执行，先核对其只读输出中的数据库路径。

本地 pre-push 会编译所有已跟踪的 Python 文件，与本次已执行的静态检查重叠。PR 会触发 API 门禁，与本次 13 项兼容检查重叠。推进 main 或 production 还会触发完整测试及发布门禁。按仓库禁止重复测试的规则，触发上述重叠项目之前须取得对应范围的明确授权，并保留各次记录。
