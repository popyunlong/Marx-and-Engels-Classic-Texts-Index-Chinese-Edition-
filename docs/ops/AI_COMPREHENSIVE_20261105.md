# 综合模式与 DeepSeek 联网

基线 `4ee1b5d`；功能分支 `codex/ai-comprehensive-20261105`。独立工作树位于 `D:/CodexData/workspaces/ai-comprehensive-20261105`。尚未部署。

## 行为与接口

新会话默认综合模式；旧会话按最后一条回答的模式恢复。综合模式按任务决定篇幅、章节和证据，不使用旧综述的 5000 字门槛或 30 条上限。模型规划、正文及完成检查均使用当前账户有权使用的模型；每次调用前重新校验权益及余额。站内检索复用篇目边界、个人文库隔离和引文核验，显式范围内无证据时不编造本书内容。

新增 `POST /api/ai/comprehensive-chat`：`question`、`messages`、`request_id`、可选 `continue_request_id`、`model`（`auto` 或授权模型）、`reasoning_effort`、`grounding_mode`（`auto/off/always`）、`scope`、`web_mode`（`auto/off/always`）。综合默认自动联网；原快速问答、研究综述新增可选 `web_mode`，默认关闭。没有联网权益时综合的自动联网降为关闭；显式强制联网被拒绝。

响应采用现有 SSE 进度与最终结果格式，进度事件可附已核验的完整章节检查点；不下发逐 token 正文或推理过程。响应包括 `actual_model`、`web_status`、`completion_status`、`continue_request_id`。取消后已完成章节保留；后续未发送的调用不会继续执行。已在途的上游调用可能完成，按真实调用计费。

网络证据采用独立 `W` 编号，最终转换成链接；站内原文沿用数字编号、卷页与阅读器链接。来源区和 Word/HTML 导出区分网络引用与联网背景参考。个人文库任务不把正文送到搜索服务。搜索仅发送规划出的公开关键词，不发送 `ori_question` 或完整聊天记录。模型看到的外部网页按不可信资料处理。

## 开关与预算

| 环境变量 | 默认 | 用途 |
|---|---|---|
| `AI_COMPREHENSIVE_ENABLED` | 关闭 | 向有对话权限的用户开放综合模式 |
| `AI_COMPREHENSIVE_ADMIN_PREVIEW` | 开启 | 管理员候选验收入口 |
| `DEEPSEEK_WEB_ENABLED` | 关闭 | 向有有效 AI 钱包权益的付费用户开放联网 |
| `DEEPSEEK_WEB_ADMIN_PREVIEW` | 开启 | 管理员联网候选验收入口 |
| `AI_COMPREHENSIVE_BUDGET_SECONDS` | 600 | 单次任务总时间预算 |
| `AI_WEB_SEARCH_LIMIT` | 8 | 单次任务搜索调用预算，含重试 |
| `AI_WEB_FETCH_LIMIT` | 12 | 单次任务网页读取调用预算，含重试 |

综合任务复用研究队列和独立 HTTP 并发池。候选证据按上下文资源预算收集，未设置最终引用条数上限。单次生成最多分配 32768 tokens，并按钱包可负担额度下调；这不是整篇文章总量上限。任务完整性由按用户要求的完成检查决定，预算耗尽返回可继续状态。

正文检查点只在当前进程内存中保存，最多 32 个任务，完成后 15 分钟到期；不在主站数据库保存完整聊天正文。续接需要同一用户、相同范围及重新校验的文库权限；实例重启或检查点过期时提示根据本机已保存正文重新提问。数据库仅保存请求标识及摘要以防重启后重复执行同一请求。不要在多进程部署中假定检查点跨实例共享。

## 计费与兼容

增量增加 `ai_tool_prices`、`ai_tool_calls`、`ai_conversation_requests`。Search/Fetch 初始人民币价格均为每个成功请求 5000 微元（¥0.005），价格版本自北京时间 2026-11-01 生效。价格参考：<https://api-docs.deepseek.com/zh-cn/quick_start/pricing/>；接口与成功计费条件：<https://api-docs.deepseek.com/guides/search/>。

联网预留与模型预留共用钱包分配和周额度保护。工具按请求单独结算，不制造模型 token；空结果和失败不扣成功请求费用；同一任务内的缓存命中不再调用供应商。工具结算和请求受理均有幂等键。综合模式不扣研究综述次数，原有综述计次规则保持。既有钱包、历史账单和 Flash 兼容别名保持有效。
