# 全书库目录审计范围与修复进度（2026-09-25）

《目录审计交付包.zip》审计的是全书库，不只是《文集》。审计报告覆盖 777 个登记核查单元（771 个公开入口、6 个历史兼容入口），扫描 20,662 个 HTML 文件和 200,490 个链接引用。中文 PDF 部分覆盖 173 个书库、614 个来源文件及 53,718 条目录；另覆盖列宁俄文全集 55 卷、MEGA 63 册原典及 1 册研究导论、MEW 德文 27 卷、英文著作集合入口和中文流式《文集》10 卷。
