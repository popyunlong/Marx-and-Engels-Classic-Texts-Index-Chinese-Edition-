## 已核实差异及处理

| 问题 | 证据与处理 |
| --- | --- |
| 四个经济学分类显示内部键且顺序不同 | 原预览直接导入 app，漏掉正式 ingestion.runtime 的 scopes 安装。隔离验收补齐 scopes、paddle 初始化；正式服务继续使用原启动器。 |
| 102 项数据库文案一致但仍有不同 | 线上另有两项本地 JSON 覆盖。验收同时采集限定公开字段的文件层和数据库层；不向生产写入预览快照。 |
| 没有坏图不代表封面齐全 | 原模板失败时删除 img；新模板保留可检测的图片元素，加载失败显示“封面暂不可用”，保持原封面接口与权限。 |
| 预览图像不是原书封面 | 预览 PDF 是三页测试正文。真实封面在生产形态候选中按源文件比对并核查解码和实际显示；不复制全量 PDF。 |
| 游客封面表现不同 | 公网抽查 403；通过受控隧道访问生产原站返回 PNG。本机默认游客权限则跳转登录。按相同身份和有效权限比对，不开放正文权限来修复展示。 |
| AI 历史抽屉关闭后页面跳动 | 新增全局 scroll-margin-top 规则使真实浏览器检查在多种宽度失败；删除该规则后 25 项浏览器检查全部通过。 |
| 浏览器限制本地存储 | 动画设置读写捕获存储异常，不影响书架及其他功能；验证减少动态效果。 |
| 内嵌处理线程未存活 | 基线已有状态，独立两版校注 worker 均 active/running、无重启。发布前后另核查独立服务和任务状态，不以该布尔值单独推断瘫痪。 |
