## 统计口径

采用用户确认的“最近可识别地区”：有效 last_ip 优先；否则在阅读、AI 历史记录中按 created_at 降序寻找有效地区；同时间先阅读来源、再按记录 ID 降序。历史仍不可用时回退 register_ip。每个非 system 账号仅计一次，所有统计读取来自同一事务快照。原始用户字段、日志不改写。

IP 表示网络出口，不代表本人居住地。有效海外结果不因国内注册记录而覆盖。无证据时不补造地区。
