连接你的客户端

MCP 地址：{{ api_base }}/mcp

Codex

将 Key 保存到环境变量 MARX_API_KEY，在 Codex MCP 配置中添加：

[mcp_servers.marx_search]
url = "{{ api_base }}/mcp"
bearer_token_env_var = "MARX_API_KEY"
tool_timeout_sec = 30
WorkBuddy

添加远程 MCP，选择 Streamable HTTP，并在凭证设置中填写 Key：

{
  "mcpServers": {
    "marx_search": {
      "type": "streamableHttp",
      "url": "{{ api_base }}/mcp",
      "headers": {"Authorization": "Bearer ${API_KEY}"}
    }
  }
}
DeepSeek Harness

配置凭据 MARX_API_KEY 后，添加 MCP 客户端插件：

- id: marx-search
  name: '@deepseek-ai/dsh-mcp-client'
  config:
    serverName: marx_search
    transport: streamable-http
    url: {{ api_base }}/mcp
    expandTemplates: true
    headers:
      Authorization: 'Bearer ${credential:MARX_API_KEY}'
    toolCallTimeoutMs: 30000

开始查询

可以对 Agent 说：“列出可查询的文库，在《马克思恩格斯文集》中查找这段引文，并读取上下文、核对版本和印刷页码。近似命中请标为待核对。”

工具顺序：list_sources → search_corpus → get_passage。近似定位须指定范围；多词共现与近似结果都是候选证据，需结合上下文判断。

串行调用。遇到繁忙提示，按返回的等待时间重试，最多三次。证据引用最长保留 24 小时，过期或语料版本变化后重新检索。
