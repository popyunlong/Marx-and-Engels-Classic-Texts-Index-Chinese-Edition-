REST API 使用

根地址：{{ api_base }}/api/v1。使用 Authorization: Bearer … 鉴权，发送 Accept: application/json 和应用标识 User-Agent: MarxCitationClient/1.0；POST 请求另带 Content-Type: application/json。

  1. GET /sources：获取书目、版本及 book: / vol: 范围标识。卷册标识使用接口返回值。
  2. POST /search：检索候选证据，如下所示。
  3. GET /passages/{evidence_id}：用搜索结果中的标识读取原文与上下文，核对版本和页码。
  4. GET /limits：查看账号剩余额度和并发限制。

Accept: application/json
User-Agent: MarxCitationClient/1.0

查询参数与结果字段

exact 为规范化精确匹配；cooccurrence 为 2–5 个空格分隔关键词共现；near_text 为近似定位，需指定著作或卷册。默认返回 10 条，最多 20 条，结果采用单次返回方式。

printed_pages 表示印刷页码，pdf_pages 表示 PDF 页序；空页码表示当前来源未提供对应信息。书目信息、原文和引文格式分别见 bibliography、text、citations。

truncated=true 表示结果有截断，search_complete=false 表示扫描未完成；可缩小著作或卷册范围后查询。

MCP 接入

MCP 地址：{{ api_base }}/mcp。选择远程 Streamable HTTP，鉴权头为 Authorization: Bearer YOUR_API_KEY，将 YOUR_API_KEY 替换为你的 Key。

Codex

将 Key 保存到环境变量 MARX_API_KEY，在 Codex MCP 配置中添加：

[mcp_servers.marx_search]
url = "{{ api_base }}/mcp"
bearer_token_env_var = "MARX_API_KEY"
tool_timeout_sec = 30
其他 MCP 客户端

在远程 MCP 设置中填写上方地址，通过凭证设置提供 Bearer Key，工具超时设为至少 30 秒。连接后可使用下列四个工具。

  1. list_sources({})：列出公共书目与可用范围。
  2. search_corpus({"q":"生产关系","mode":"exact","scope":["book:文集"],"limit":10})：查询证据。
  3. get_passage({"evidence_id":"搜索结果中的 evidence_id"})：读取上下文。
  4. get_api_limits({})：查看当前账号额度。

例如：“在《马克思恩格斯文集》中查找‘生产关系’，读取相关原文的上下文，并列出版本和印刷页码。”

额度与常见问题

每账号数据调用默认并发 1，每分钟 {{ per_minute }} 次；多个 Key 和客户端共用额度，不消耗站内 AI token。额度查询不计次，可在数据请求执行期间调用。实际限制和剩余次数见 GET /limits 或 get_api_limits。

参数错误、鉴权失败或未取得执行名额的请求不计次，开始执行后计次。证据标识最长有效 24 小时，过期后重新检索。

参数或请求大小有误（400 / 413）
检查查询、模式和范围；范围使用书目接口返回的 book: 或 vol: 标识，请求体限 16 KiB。
Key 或权限有误（401 / 403）
401：检查 Key 是否缺失、错误或已撤销。403 且返回 JSON：检查会员状态及接口权限。
证据已失效（404 / 409）
正文查询返回 404 表示证据不存在或已过期，409 表示语料版本变化；重新检索取得新的证据标识。
请求过于频繁或服务繁忙（429 / 503）
当 retryable=true 时，按 Retry-After 或 retry_after_seconds 等待并退避，最多重试两次；其余情况根据返回的错误信息处理。
超时或网络中断（504 等）
客户端超时建议至少 30 秒。执行结果未确认时不自动重发；可缩小查询范围，检查连接后再发起查询。
响应出现 Cloudflare 1010
记录请求时间和 CF-Ray，联系管理员核查访问规则。
提供故障信息

提供请求时间、HTTP 状态及 X-Request-ID／CF-Ray 即可。MCP 工具错误可从 structuredContent.error 读取，isError=true 表示调用出错。
