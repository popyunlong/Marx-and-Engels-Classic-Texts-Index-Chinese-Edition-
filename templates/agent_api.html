REST API 使用

根地址：{{ api_base }}/api/v1。使用 Authorization: Bearer … 鉴权，发送 Accept: application/json 和应用标识 User-Agent: MarxCitationClient/1.0；POST 请求另带 Content-Type: application/json。

  1. GET /sources：获取书目、版本及 book: / vol: 范围标识。卷册标识使用接口返回值。
  2. POST /search：检索候选证据，如下所示。
  3. GET /passages/{evidence_id}：用搜索结果中的标识读取原文与上下文，核对版本和页码。
  4. GET /limits：查看账号剩余额度和并发限制。
POST {{ api_base }}/api/v1/search
Authorization: Bearer YOUR_API_KEY
Accept: application/json
User-Agent: MarxCitationClient/1.0
Content-Type: application/json

{"q":"生产关系","mode":"exact","scope":["book:文集"],"limit":10}

exact 为规范化精确匹配，仍需核对原文；cooccurrence 为 2–5 个空格分隔关键词共现；near_text 为近似定位，必须指定著作或卷册。默认 10 条，最多 20 条，没有遍历式分页。

返回的 printed_pages 是印刷页码，pdf_pages 是 PDF 页序，两者不能混用。结合 bibliography、page_refs、text 与 citations 核对引文。缺失页码不要自行补造；truncated=true 或 search_complete=false 表示结果不能视为穷尽。

MCP 接入

MCP 地址：{{ api_base }}/mcp。选择远程 Streamable HTTP，鉴权头为 Authorization: Bearer <你的 Key>。Key 与 REST 共用。

Codex

将 Key 保存到环境变量 MARX_API_KEY，在 Codex MCP 配置中添加：

其他 MCP 客户端

在客户端的远程 MCP 设置中填写上方地址与鉴权头，优先通过凭证设置保存 Key。不同客户端的环境变量替换语法不同，不能把变量名当作 Key 原样发送。连接后应能看到下列四个工具；配置保存成功不等于已成功调用。

  1. list_sources({})：列出公共书目与可用范围。
  2. search_corpus({"q":"生产关系","mode":"exact","scope":["book:文集"],"limit":10})：查询证据。
  3. get_passage({"evidence_id":"搜索结果中的 evidence_id"})：读取上下文。
  4. get_api_limits({})：查看当前账号额度。

可向支持 MCP 的客户端提出：“先列出可查询的文库，在《马克思恩格斯文集》中查找这段引文，再读取原文上下文，核对版本和印刷页码；近似命中标为待核对，没有证据时明确说明。”

额度与错误处理

工具顺序：list_sources → search_corpus → get_passage。多词共现与近似结果都是候选证据，需结合上下文判断。

串行调用。遇到繁忙提示，按返回的等待时间重试，最多三次。证据引用最长保留 24 小时，过期或语料版本变化后重新检索。

  • 400：检查查询、模式和范围；REST/MCP 不支持篇章参数。
  • 401：检查 Key 是否缺失、错误或已撤销。
  • 403 且为应用 JSON（如 membership_required）：检查会员及接口权限。若正文为 error code: 1010，则是 Cloudflare 边缘拒绝；提供请求时间和 CF-Ray 联系管理员，无需反复生成 Key。
  • 404：证据不存在或过期；409：语料版本变化。两者均需重新检索。
  • 429/503：按 Retry-After 或 retry_after_seconds 等待，最多重试三次；504：缩小书卷范围或调整查询。

排障时保存请求时间、HTTP 状态、CF-Ray、X-Request-ID、内容类型和有限错误摘要；隐藏 Key，不记录完整鉴权头或论文内容。MCP 错误在 structuredContent 中返回，并设置 isError。
